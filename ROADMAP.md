# Roadmap

Subtrack Web is intentionally focused on private self-hosting.

## Near term

- Add automated API and database integration tests
- Improve validation for portable data imports
- Add an authenticated reverse-proxy deployment guide
- Add backup integrity and restore smoke tests
- Add accessible spending calendar and daily payment heatmap

## Later

- Optional multi-currency display rules
- Historical import tools
- Additional reminder channels
- Multi-user support only after a complete authorization design

Roadmap items are not release commitments. Security, data integrity and reliable upgrades take priority.
